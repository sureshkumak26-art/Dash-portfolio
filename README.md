# Daksh Kumar — Cinematic Portfolio

A premium, dark cinematic portfolio for Daksh Kumar, showcasing web, app, automation, Telegram, and AI projects.

Built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

Update project links and social profiles in `app/page.tsx`.
